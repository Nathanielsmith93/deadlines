# Deadlines

Static, passphrase-encrypted deadline dashboard.

`index.html` contains only AES-256-GCM ciphertext. The passphrase is not in the
file and cannot be recovered from it. Without it the page shows a lock screen
and nothing else.

Nothing in this repo is generated by hand - rebuild with:

    python build_dashboard.py --lock --publish

from the parent project, which re-encrypts and overwrites `index.html` here.
